# Roadmap

This repository maintains a Windows-only RTL presentation patch for Codex Desktop.
The roadmap is intentionally small and focused on compatibility, safety, and documentation quality.

## Current Focus

- Keep the RTL patch compatible with the latest supported Codex Desktop release.
- Preserve left-to-right behavior for code blocks, terminals, editors, and developer tooling.
- Maintain the safe local-install and local-uninstall workflow.
- Keep the repository documentation aligned with the current project state.

## Near-Term Work

- Verify patch behavior after Codex Desktop updates.
- Improve installer and recovery guidance where needed.
- Keep the release documentation ready for future tagged releases.

## Longer-Term Direction

- Reduce maintenance risk by tightening update detection and compatibility checks.
- Document supported environments and recovery steps clearly.
- Keep the project limited to RTL presentation changes and related tooling.

## Out of Scope

- macOS support.
- Browser or UI redesign work unrelated to RTL presentation.
- Changes to Codex functionality beyond layout and direction handling.
